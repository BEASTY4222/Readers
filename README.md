# Readers overview

    Readers is a place where people who like books can connect and share a common community. 
    Comment, like and share you toughts about some of your favorite books.

# Technologies
    
    This is a C# ASP.NET Core MVC Web app

# How to start up the project on your own machine
   
    1.First make sure you have .NET 10+
    2.Download the repo and unzip it/extract it OR clone the repo via git 
    	git clone GITHUB_PROJECT_URL
    3.Go into the Readers folder and then again into the Readers folder until you see folders like:
     	view, controllers, areas, wwwroot and etc.
    4.Now open the filepath in the terminal/cmd or right-click in the folder explorer, and click open in terminal
    5.Now type in "dotnet run" and press ENTER
    6.You will be able to see and open the site on the localhost:XXXX show in the terminal
